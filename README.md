# Incidentes de tránsito en Coronel Rosales

## API & REACT Frontend

Instrucciones para iniciar los dos servicios

- Backend API REST Mock con json-server
- Frontend con REACT

## Instalación e Backend API REST Mock

- cd backend
- npm install
- npm run mock
- La API estará en http://localhost:3001

## Instalación e inicio Frontend

- cd frontend
- npm install
- npm run dev
- El sitio estará en http://localhost:5173/
